# HuaweiCloud Encryption SDK (Python)

华为云加密 SDK Python 版，提供数据加解密、密钥胶囊、LTS 日志上报等功能，支持 AES-GCM、SM4-GCM/CBC、SM2 等算法。

## 环境要求

- Python >= 3.9
- Linux（x86_64 / ARM64）

## 文档

- [密钥胶囊开发指南](doc/development_guide_key_capsule.md) — 密钥胶囊加解密的完整开发指南

## 项目结构

```
├── doc/                    # 文档
├── examples/               # 示例程序和测试脚本
├── src/                    # SDK 源码
├── tests/                  # 单元测试
└── pyproject.toml          # 项目构建配置
```
